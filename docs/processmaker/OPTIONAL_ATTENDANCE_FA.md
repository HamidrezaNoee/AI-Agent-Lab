# رفع الزام اشتباه ساعت حضور

فرم FR-MTG-003 در PMX مرجع، MTG_AttendanceTime را با required=false تعریف کرده
است؛ اما تریگر AFTER، مقدار خالی را با regex رد می‌کرد. این اصلاح فقط همان شرط
را تغییر می‌دهد: خالی مجاز است؛ مقدار غیرخالی همچنان باید HH:mm باشد.

## اعمال روی فرایند موجود

در ProcessMaker Designer، فرایند «مدیریت جلسات» را باز کنید و تریگر زیر را
ویرایش کنید؛ تریگر جدید نسازید و ترتیب اتصال آن را تغییر ندهید:

- نام: TRG-MTG-003-AFTER-SaveMeetingMinutesAndSyncSQL
- UID: fe88e8afc98ca69585ab0f5fb16bbf74

فایل minutes-after-optional-attendance.php کنار همین راهنما، متن کامل تریگر
اصلاح‌شده براساس PMX فرستاده‌شده در ۷ اکتبر است. نسخه فعلی تریگر را نگه دارید؛
اگر از آن تاریخ تغییری داده‌اید، فقط شرط زیر را اصلاح کنید تا تغییرات دیگر حفظ شود.

شرط قبلی:

```php
if ($status === 'Present' && !preg_match('/^([01]\d|2[0-3]):[0-5]\d$/', $time)) {
```

شرط جدید:

```php
if ($status === 'Present' && $time !== '' && !preg_match('/^([01]\d|2[0-3]):[0-5]\d$/', $time)) {
```

برای کپی متن کامل در PowerShell، از ریشه مخزن:

```powershell
Get-Content -Raw -Encoding UTF8 ".\docs\processmaker\minutes-after-optional-attendance.php" | Set-Clipboard
```

متن را در ویرایشگر همان تریگر جایگزین و ذخیره کنید. این فایل تگ `<?php` ندارد؛
قالب اصلی و متغیرهای اختصاصی ProcessMaker را حفظ می‌کند. هیچ SQL UPDATE،
ایجاد Case یا مهاجرت داده‌ای لازم نیست. استقرار AVAN به‌تنهایی کد تریگر سرور
ProcessMaker را تغییر نمی‌دهد.

پس از استقرار AVAN، فرم را تازه کنید. فرد حاضر با ساعت خالی نباید مانع ارسال
باشد؛ 17:30 باید پذیرفته شود؛ 25:90 باید همچنان رد شود. این پذیرش روی یک پرونده
آزمایشی در سرور واقعی باید کنترل شود؛ تست‌های کد جای آن را نمی‌گیرند.
