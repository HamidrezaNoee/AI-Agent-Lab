# بازبینی AVAN — ۳ اکتبر ۲۰۲۶

بازبینی کد تولید، قراردادهای اتصال، دسترسی‌ها، بسته‌بندی و آزمون‌های تجاری انجام شد.
نتیجه آزمون نهایی: ۳۳۵ آزمون و ۵۵ زیرآزمون موفق، بدون شکست. دو آزمون رابط DOM
برای دبیر و فضای کاری فرایند نیز موفق بودند. بررسی نحوی JavaScript موفق بود.
آزمون بسته‌بندی، فایل‌های COPY را در بسته‌ای مستقل کپی و برنامه را اجرا می‌کند.
یک هشدار منسوخ‌شدن httpx در TestClient وجود دارد؛ شکست آزمون نیست.

## اصلاحات

- منوهای ثابت جلسه با رجیستری آداپتور و انتخاب بسته زیر هر اتصال جایگزین شد.
- کارتابل، اعلان و پیش‌نویس بر اساس فرایند منتخب جدا شد؛ پاسخ دیررس فرایند قبلی
  پس از تعویض فرایند در صفحه جدید نمایش داده نمی‌شود.
- مجوز بخش‌های تحلیلی مستقل حفظ شد؛ کاربران گزارش‌گیر اطلاعات دبیر را دریافت نمی‌کنند.
- پرسش‌ها، گزارش و تاریخچه تحلیل به UID فرایند منتخب محدود شدند.
- هم‌پوشانی فرایندهای بسته‌ها و استفاده از آداپتور ناشناخته رد می‌شود.
- پیش از ارسال وظیفه، داده تازه REST با داده مرتبط فرم مقایسه می‌شود؛ تغییر هم‌زمان
  پرونده مانع نوشتن پیش‌نویس قدیمی می‌شود.
- افراد و فرم دعوت‌نامه پیش از ایجاد پرونده دوباره اعتبارسنجی می‌شوند.
- تأیید رئیس با اطلاعات ضروری پاک‌شده پذیرفته نمی‌شود.
- محاسبه مهلت تاریخ میلادی بدون ساعت، ساعت فرم را لحاظ می‌کند.
- تطبیق نقل‌قول شواهد با متن واقعی انجام می‌شود و به escapeهای JSON وابسته نیست.
- آزمون بسته‌بندی تمام مبدأهای COPY چندفایلی را بررسی می‌کند.

## حدود تأیید

اتصال زنده به ProcessMaker، SQL سازمان، Keycloak و مدل در محیط بررسی فراهم نبود.
ارسال واقعی دعوت‌نامه، تریگرهای نصب‌شده، صوت مدل، تحویل اعلان و گردش انتهابه‌انتهای
پرونده در محیط سازمان هنوز باید بررسی شوند. Docker CLI این محیط موجود نبود؛
ساخت واقعی image انجام نشد. دانلود Chromium کامل نشد، بنابراین بررسی تصویری
مرورگر و screenshot انجام نشد؛ آزمون DOM جای آن را به‌طور کامل نمی‌گیرد.

دو مجموعه آزمون نمونه قدیمی ریشه پروژه (`test_document_chunking` و
`test_knowledge_core`) به علت نبود کتابخانه بومی `libodbc.so.2` قابل جمع‌آوری نبودند.
آزمون‌های تجاری بدون حذف آزمون اجرا شدند. Docker تولید unixODBC را نصب می‌کند،
اما موفقیت این آزمون‌های نمونه در این محیط ادعا نمی‌شود.

آداپتور عمومی فعلاً فقط‌خواندنی است. اجرای هوشمند فرایندهای غیرجلسه نیازمند
آداپتور اختصاصی است. اعلان‌های پنل با polling دریافت می‌شوند. محدودیت تعداد
نتایج کارتابل با علامت truncated بازگردانده می‌شود؛ این نسخه تضمین push بیرونی
یا نمایش نامحدود همه پرونده‌ها نمی‌دهد.
