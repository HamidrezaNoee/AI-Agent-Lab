# مرجع ProcessMaker این نسخه

مرجع، دو فایل نهایی `BPM_PRO_MTG_001_فرایند_مدیریت_جلسات-5 (1).pmx` و `BPM_PRO_MTG_002_فرایند_اقدام_مصوب_جلسه-5 (1).pmx` با metadata نسخه 3.2.1 / PHP 5.6.31 است. فایل‌های PMX اصلاح‌شده جداگانه همراه پاسخ تحویل می‌شوند.

در کپی اصلاح‌شده فقط بقایای اتصال mssql، تریگر config بلااستفاده، تریگر آزمایشی غیرمتصل، دستور و فیلدهای Debug/DBSync و بارگذاری فایل CustomeFormHelper.js حذف شدند. منطق ضروری JavaScript داخل هر فرم قرار گرفت. شناسه فرایند، تسک، فرم، انتساب و مسیرهای گردش کار حفظ شدند؛ تریگرهای تجاری نسخه نهایی بازنویسی مجدد نشدند.

هنگام Import، فرایندها را با همان UID حفظ کنید. واردکردن به‌عنوان فرایند جدید با UID تازه، ارتباط والد/فرزند و قرارداد Agent را تغییر می‌دهد. ابتدا در workspace آزمایشی از همین نسخه Import و مسیر کامل را اجرا کنید؛ سپس نسخه پشتیبان قابل بازیابی از workspace اصلی بگیرید و ارتقای فرایند را انجام دهید. نیازی به حذف بانک SQL Server قبلی نیست.
