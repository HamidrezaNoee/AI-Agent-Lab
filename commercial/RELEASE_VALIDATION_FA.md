# گزارش اعتبارسنجی تحویل — ۲۰۲۶-۰۹-۲۳

- مجموع ۱۹۹ تست Python و ۵۵ زیرآزمون قبول شدند. اجرای کامل پیش از آخرین اصلاح گزارش ۱۹۸ تست بود؛ آزمون افزوده و مجموعه مرتبط بعد از اصلاح نیز قبول شد.
- آزمون مرورگر Chromium با API شبیه‌سازی‌شده: سابقه گفتگو، پاسخ مستند، تبدیل فایل صوت در UI، ویرایش/نسخه/تأیید/خروجی/بازگشایی دبیر، تأیید مشاهده هشدار، فعال‌سازی پایش، BI و CSV، نمایش موبایل و پنل تنظیمات قبول شد.
- داده تمام ۱۰۰۸ سناریو از تبدیل متغیرهای بومی و parser داده سریال‌شده PHP عبور کرد. ۴۰۳۲ اقدام، ۵۰۴ بسته، ۳۵۲۸ باز و ۳۰۲۴ تأخیردار در تاریخ مبنا با انتظار مجموعه تطبیق داشت.
- بازاجرای Import بدون تکرار، توقف در پاسخ نامشخص شبکه و جلوگیری از اجرای هم‌زمان با checkpoint مشترک آزموده شد.
- امضای لایسنس، انقضا، ظرفیت و جلوگیری از پذیرش کاربر اضافه تحت تراکنش آزموده شد.
- جداسازی مجوز گفتگو، نسخه پیش‌نویس، کنترل منبع صوت، چرخش مجوز پایش و توقف در ابطال دسترسی آزموده شد.
- COPYهای image عملیاتی در پوشه مجزا بازسازی و import/بوت بدون بانک تنظیم‌شده آزموده شد. الگوی اشتباه dockerignore که secretary_agent.py را حذف می‌کرد اصلاح شد.
- syntax جاوااسکریپت و git diff بررسی شدند. پیکربندی CI شامل تست‌ها، مرورگر، build سه image، اعتبارسنجی Compose و gateway HTTPS است.

در این محیط Docker daemon و شبکه سازمان در دسترس نبود. build واقعی Docker، Keycloak تازه، اتصال SQL Server/MySQL، Import در PM 3.2.1، فراخوانی واقعی AI/صوت و TLS مقصد تست نشده‌اند. تست‌های شبکه از mock استفاده می‌کنند. نتیجه CI واقعی را در PR بررسی کنید؛ صرف وجود workflow به معنای قبولی build نیست.

این تحویل PBIX/SSAS، نوشتن مستقیم Agent در ProcessMaker، پیامک/ایمیل خودکار و HA چند replica ندارد. BI وب شاخص‌های مشترک گردش کار همه فرایندها را پوشش می‌دهد؛ فیلدهای کسب‌وکاری اختصاصی نیازمند نگاشت جدا هستند.
