# راهنمای بازبینی نسخه نمایشی رابط وب آوان

این نسخه، یک **پیش‌نمایش مستقل، فارسی، واکنش‌گرا و فقط روی localhost** است. داده‌های آن فقط از فایل ۱۰۰ سناریوی کاملاً ساختگی داخل مخزن خوانده می‌شوند. این برنامه هیچ اتصالی به SQL Server، ProcessMaker، OpenAI، هویت سازمانی یا بانک ندارد و به‌هیچ‌عنوان جایگزین API تجاری و مجوزهای امنیتی آن نیست.

## نمایش فوری روی لپ‌تاپ ویندوز (PowerShell)

```powershell
$repo = "D:\A Project\17 meeting ai agent\Azure\AI-Agent-Lab-GitHub"
$python = "D:\A Project\17 meeting ai agent\Azure\AI-Agent-Lab\.venv\Scripts\python.exe"
git -C $repo pull --ff-only origin main
cd $repo
& $python -m uvicorn commercial.demo_preview:app --host 127.0.0.1 --port 8090
```

سپس در مرورگر **فقط** این نشانی را باز کن:

http://127.0.0.1:8090

به‌هیچ‌وجه `--host 0.0.0.0` یا یک پورت اینترنتی/دامنه عمومی برای این پیش‌نمایش انتخاب نکن. پس از بازبینی، در پنجره PowerShell دکمه `Ctrl+C` را بزن. برای اجرا **نیازی به واردکردن رمز SQL یا کلید OpenAI نیست**.

## موارد قابل بررسی

۱. داشبورد فارسی و شاخص‌های ۱۰۰ جلسه و ۳۰۰ اقدام نمونه در ۱۰ حوزه خودرویی.
۲. فهرست، جست‌وجو، فیلتر و پرونده کامل جلسات همراه با مصوبات، مسئولان، موعد و پیگیری.
۳. دستیار نمونه برای پیدا کردن جلسات مرتبط بر اساس واژه‌های فارسی **بدون فراخوانی مدل زبانی**.
۴. ماژول دبیر: پیش‌نویس دستور جلسه و فهرست اقدامات نمونه.
۵. ماژول تحلیل: شمارش و نمودار وضعیت جلسات و اقدامات.
۶. ماژول پایش: فهرست درخواستی اقدامات باز و دارای موعد گذشته.
۷. صفحه مدیریت ماژول‌ها: روشن و خاموش کردن نمایشی ماژول‌های ۲، ۳ و ۴. این کلیدها صرفاً وضعیت حافظه مرورگر را عوض می‌کنند و پس از بارگذاری دوباره به حالت اولیه برمی‌گردند. **هیچ خرید، تغییر SQL یا صدور مجوزی رخ نمی‌دهد.**

در API آزمایشی واقعی محصول، کنترل خرید، مدت اعتبار مجوز، نقش مدیر و مجوز هر جلسه در SQL و API بررسی می‌شود و قبلاً با داده ساختگی آزمایش شده است. **این پیش‌نمایش مستقل به هویت واقعی و API متصل نیست.** کد پنل متصلِ جداگانه با ورود OAuth/PKCE نیز در پروژه اضافه شده، اما تا زمان ارائه مشخصات واقعی IdP، صدور توکن معتبر و ثبت عضویت کاربران آزمایشی امکان ورود عملیاتی ندارد؛ راهنمای آن در `commercial/CONNECTED_PORTAL_SETUP_FA.md` قرار دارد. این دو پنل را با یکدیگر اشتباه نگیر.

## آزمون‌های کدنویسی (بدون اتصال واقعی)

```powershell
cd "D:\A Project\17 meeting ai agent\Azure\AI-Agent-Lab-GitHub"
$python = "D:\A Project\17 meeting ai agent\Azure\AI-Agent-Lab\.venv\Scripts\python.exe"
& $python -m pip check
& $python -m unittest discover -s commercial/tests -v
```

آزمون‌های `commercial/tests/test_demo_preview.py` و `commercial/tests/test_pagination.py` جدیدند. آزمون‌های SQL واقعی فقط در محیط آزمایشی جداگانه و با تنظیمات قبلی مجازند. در این نسخه هیچ تغییری در جداول عملیاتی ProcessMaker انجام نشده است.

## محدودیت صریح این تحویل

این تحویل یک **پیش‌نمایش قابل بررسی UI + توسعه API آزمایشی صفحه‌بندی جلسات** است، نه آماده‌سازی کامل نسخه تولیدی. سامانه ورود مشتری با ارائه‌دهنده هویت واقعی، یکپارچه‌سازی پنل با API دارای توکن، تبدیل گفتار به متن، چت واقعی OpenAI، اعلان‌های زمان‌بندی‌شده، پرداخت و صدور واقعی لایسنس، و انتقال کنترل‌شده داده واقعی ProcessMaker هنوز تکمیل نشده‌اند. برای انتشار اینترنتی، اتصال عملیاتی یا دریافت وجه از مشتری استفاده نشود.
